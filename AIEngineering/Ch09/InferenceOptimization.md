AI Models : Inference Optimization

AI Model Inference Optimization is an interdisciplinary field such that collaboration among model researchers, application developers, system engineers, compiler designers, hardware architects, and even data center operators. It can be done at model, hardware and service level. 

Model level we can reduce the pre-trained model size or develop more efficient architectures. Ex Overcome the computational bottleneck of the transformers models attention mechanism.

Hardware level we can design more powerfull hardware systems like distributed computation.

Service level : For every users request we needed to run the model for inference service accommodation. So, we can use techniques that optimizes models for specific hardware. We needed to consider usage and traffic pattern to efficiently allocate resources to reduce latency and cost.
