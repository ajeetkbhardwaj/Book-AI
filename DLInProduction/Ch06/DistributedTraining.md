Deep Learning Model Architectures for most of application can be trained onto the single machine with GPU. There are the cases where 

1. Large amount of big data don't fit into single machine
2. Single hardware did capable of handling huge computation during training process of the large dl model architectures.

Problem of scalability : How to scale out the model training ?
We can use clusters of machine consisting of multiple GPU. Now, we needed to some how distribute our model training process efficiently over these clusters.
